# 🛒 Purchase Decision

## Machine Learning Dashboard for Customer Purchase Likelihood

A machine learning project that analyzes product ratings, customer reviews, sentiment, pricing, discounts, and review information to predict whether a customer is likely to purchase a product.

---

## 📌 Project Overview

The project focuses on understanding how product ratings and customer reviews can influence purchase decisions.

A machine learning model is trained using product-related and review-related features to predict **Purchase Likelihood**.

The project also includes an interactive Gradio dashboard where users can enter product and customer review information and receive a purchase-likelihood prediction.

---

## 🎯 Objectives

- Analyze customer reviews and product ratings.
- Perform data preprocessing and exploratory data analysis.
- Convert customer reviews into numerical features using TF-IDF.
- Analyze customer sentiment.
- Train machine learning classification models.
- Predict customer purchase likelihood.
- Evaluate model performance using multiple metrics.
- Provide an interactive user-friendly dashboard.
